How it works. Each button asks NovelWorks to run its Format on the part you chose. Nothing is formatted in Word itself — the app does the work, the same Format as on its own Format page.

The first change of a sitting makes the next version of the manuscript, like every write the app makes. This window closes with the old version; open the new one's Format again.

If nothing happens, open NovelWorks and work on this book, then press again.
